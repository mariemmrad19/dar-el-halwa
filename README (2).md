# Dar El Halwa

## Présentation du projet

Dar El Halwa est un site web de présentation d'une pâtisserie tunisienne spécialisée dans les pâtisseries traditionnelles et les mignardises. Il permet aux visiteurs de découvrir la pâtisserie, de consulter les produits et de remplir un formulaire de commande personnalisée.

## Pages du site

- **`index.html`** : page d'accueil et présentation de la pâtisserie.
- **`carte.html`** : présentation des catégories de produits et de leurs prix.
- **`commande.html`** : formulaire de commande personnalisée.

## Contenus multimédias

- **`patt.jpg`** : image utilisée dans le site.
- **`temoignage.mp4`** : vidéo de témoignage.
- **`avis_clients.mp3`** : fichier audio lié aux avis des clients.

## Technologies et outils utilisés

- **HTML5** : structure des pages web.
- **Visual Studio Code** : édition du code.
- **Git** : gestion des versions.
- **GitHub** : hébergement du dépôt du projet.

## Objectifs du projet

- Présenter la pâtisserie et ses produits.
- Organiser les produits en différentes catégories.
- Faciliter la navigation entre les pages.
- Permettre aux clients de remplir un formulaire de commande.
