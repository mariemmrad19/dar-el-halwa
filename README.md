# Dar El Halwa
 Dar El Halwa est un site web de présentation et de vente de pâtisseries tunisiennes. Il permet aux visiteurs de découvrir les différents produits proposés par la pâtisserie, de consulter les prix et de commander un gâteau personnalisé.
 ## Présenation:
 Ce projet a pour objectif de présenter une pâtisserie tunisienne et ses différents services à travers un site web simple et facile à utiliser.
 ## Les pages de site
 Le site contient trois pages principales :
- index.html :  
 présente la pâtisserie, ses produits, ses services et ses informations de contact.
- carte.html :
 affiche les différentes catégories de produits, leurs prix et leur disponibilité.

- commande.html :
 contient un formulaire permettant aux clients de commander un gâteau personnalisé.
 ## Les fonctionnalités : 
 Le site permet de consulter les produits, de découvrir les services proposés et de remplir un formulaire de commande. Il contient également des liens de navigation, un tableau de prix, des images, une vidéo et un fichier audio .
## Les technologies utilisées :
- HTML5
- Visual Studio Code
- Git et Github
